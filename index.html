CoinQuant · Team Lead · Private codebase

Event-driven backtesting platform

A serverless system on AWS that runs trading strategy backtests in parallel.

  • Python
  • AWS Lambda
  • AWS SQS
  • PostgreSQL

800+ backtests running in parallel

Problem
Users run many backtests at once, and each one costs credits. Some jobs will always fail, from a network error to an invalid parameter, so the system has to recover cleanly: no lost work, no duplicate results, no duplicate refunds.
What I built
Each backtest request goes onto an SQS queue and is processed by AWS Lambda workers, which write results to PostgreSQL. I designed and built the Lambda system and its queues.
Key decisions
  • Failed jobs go to a dead-letter queue and can be redriven (replayed) once the cause is fixed.
  • Result writes are idempotent, with retry and backoff, so a retried job never writes its results twice.
  • Credit refunds are idempotent too, so a failed job refunds the user exactly once.

Job Hunter

Finds new remote software jobs that can hire someone living in Lebanon, then helps apply to them.

  • Python
  • SQLite
  • Claude
  • DeepSeek
  • Gmail SMTP/IMAP

295 automated tests

View the code on GitHub ↗
Problem
Many "remote" jobs can only hire in certain countries, and the posting often doesn't say so clearly. Checking every listing by hand takes hours.
What I built
A Python tool that runs every day. It pulls listings from job boards, company career pages and Hacker News, stores them in SQLite, and uses plain rules to decide whether each job can hire from Lebanon, with a readable reason for every decision. A local web app shows who to email at each company, drafts the email, sends it from Gmail and tracks replies, bounces and follow-ups. It also writes a tailored CV and cover letter for each shortlisted job with Claude and DeepSeek.
Key decisions
  • AI only judges the unclear jobs, and must back every answer with an exact quote that the code then finds word for word on a page it fetched itself. No quote, no decision.
  • Tailored CVs are checked against a master profile, so they never claim a skill, number or job that isn't true.
  • Sending is safe to click twice: each email is recorded before it goes out, and a unique database rule blocks a second send.

Interactive backtest chart

The chart for reviewing a backtest's trades on top of market data.

  • Next.js
  • TypeScript
  • TradingView Lightweight Charts

The career timeline at the top of this page uses the same charting library.

Problem
To trust a backtest, you need to see where each trade opened and closed, next to the indicators the strategy used, across long stretches of market data.
What I built
An interactive chart in Next.js and TypeScript on TradingView Lightweight Charts, with trade entry and exit markers, indicator panes, and filters for winning and losing trades.
Key decision
Candle and indicator data is lazy-loaded as you pan, instead of loading the whole history up front.
